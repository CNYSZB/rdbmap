快捷键 / 操作说明
手机端
空白处拖动旋转视角（同时可点选编辑物体） 点按物体选中 / 取消选中 拖动手柄移动 / 旋转 / 缩放物体 上 / 下 / 左 / 右移动视角前后左右 ⇧ / ⇩视角上升 / 下降 💾 顶部保存一键保存地图（不弹窗） 🔲 多选开启后可拖框多选 ↻ / ↺ 90°选中物体绕垂直轴旋转 90° 📥 导入贴图纹理下拉选「导入贴图」选择图片
预览（手机）
单指滑动旋转视角 十字键移动 · ⇧跳 · ⇩下落
视角（桌面）
右键拖动转视角（自动锁定鼠标，松开解锁） W A S D前后左右 空格 上升 Ctrl下降 Shift加速 滚轮沿视线前后 F把视角对准选中的物体
选择
左键选中 Shift + 左键加选 / 取消选中 空白处拖动框选（按住 Shift 累加） Ctrl + A全选 Esc取消选择
编辑
1选中工具 2移动工具 3旋转工具 4缩放工具 Ctrl + Z撤销 Ctrl + Shift + Z重做 Ctrl + Y重做 Ctrl + D复制 Delete删除 Shift + 拖轴缩放时等比
其他
Ctrl + S立即存档 Ctrl + E导出地图 P进入 / 退出预览 F1打开这一页
